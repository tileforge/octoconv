<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → API → metrics label | The client's `client_id` (resolved from an API key, not from request body) becomes a Prometheus label value — a value crossing into unbounded in-memory/series state |
| job row → rollup table | Job-derived values (engine, byte sizes) become durable accounting rows a future quota reads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-51-01 | Denial of Service | `octoconv_client_job_outcomes_total` label set | mitigate | Ceiling of `METRICS_CLIENT_ID_CEILING` (default 200) distinct values enforced in `clientLabel`; overflow collapses to one stable `overflow` value; malformed/empty/nil-UUID ids never consume a slot (ACCT-04, tested) |
| T-51-02 | Denial of Service | terminal transition path | mitigate | No `CHECK (engine ...)` on `client_usage_daily`: a stale allow-list must never be able to abort the transaction that marks a job `done` |
| T-51-03 | Information disclosure | `/metrics` exposure of client UUIDs | accept | `client_id` is an internal opaque UUID for internal company services, not PII; `/metrics` has the same exposure surface as the existing engine/status labels; no new endpoint is introduced |
| T-51-04 | Tampering | client deletion vs. usage history | accept | `client_usage_daily.client_id` FK is `ON DELETE CASCADE`: removing a client removes its usage history deliberately, matching `presets`' existing cascade semantics |
| T-51-SC | Tampering | dependency supply chain | mitigate | This plan installs no packages; `go.mod`/`go.sum` unchanged is an acceptance criterion |
</threat_model>

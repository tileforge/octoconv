## Метод очистки PDF

### Чем чистим

| Option | Description | Selected |
|--------|-------------|----------|
| Пересборка через ghostscript | Выход генерируется; не зависит от полноты списка имён и от слепоты /ObjStm | ✓ |
| Полная перезапись qpdf с удалением по списку | Структура сохраняется, но удаляется только названное | |
| Гибрид qpdf → gs при находках | Дешевле на чистых файлах, но два пути с разными гарантиями | |

**Notes:** решающим оказался факт из 58-CONTEXT.md D-02a — `/ObjStm` прячет всё,
кроме stream-объектов и словаря шифрования. Blacklist наследует ровно эту
слепоту; пересборка от неё не зависит. Плюс требование SANI-04 про полную
перезапись выполняется по конструкции.

### Что с потерянной точностью

| Option | Description | Selected |
|--------|-------------|----------|
| Сообщать в отчёте отдельно от угроз | Два списка: удалённые угрозы и утраченные возможности | ✓ |
| Описать в контракте один раз | Дешевле, но клиент узнаёт о потере, когда что-то сломается | |
| Отказывать при наличии форм | Не портить молча, но целый класс документов становится необслуживаемым | |

## Независимый верификатор

### Чем проверяем PDF

| Option | Description | Selected |
|--------|-------------|----------|
| pdfcpu, полный разбор выхода | Распаковывает /ObjStm; фаза 58 уже запланировала его сюда | ✓ |
| qpdf, развёртка в QDF и поиск по токенам | Другой язык, сильнее независимость, но проверка по тексту | |
| Оба | Два взгляда, но два источника ложных срабатываний и больше времени | |

**Notes:** ключевое свойство — верификатор не должен наследовать слепоту
чистильщика. Верификатор, слепой там же, доказывает не чистоту, а собственную
неспособность посмотреть.

## Отказ и границы отчёта

### Верификатор не смог разобрать выход

| Option | Description | Selected |
|--------|-------------|----------|
| Не смог разобрать = отказ | Непроверенный выход не попадает в S3 вообще | ✓ |
| Отдавать с пометкой unverified | Клиент решает сам, но файл после sanitize будет считаться чистым всяким, кто не читал отчёт | |
| Повторить строже, потом отказ | Второй путь со своим таймаутом и своими гарантиями | |

**Notes:** тот же принцип, что удерживал `absent` в фазе 59 — «не смог
посмотреть» никогда не засчитывается за «там ничего нет».

| Option | Description | Selected |
|--------|-------------|----------|

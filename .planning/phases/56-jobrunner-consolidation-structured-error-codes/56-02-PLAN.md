<objective>
Create the single source of truth for the synchronous (HTTP 4xx/429) machine-readable error-code
vocabulary, per 56-CONTEXT.md D-01/D-02/D-03/D-06, and adopt it in the two packages that emit
error bodies OUTSIDE `internal/api`: `internal/auth` (which carries its own duplicated
`writeError`) and `internal/ratelimit` (which already emits `"code": "rate_limited"` as a local
literal).

`internal/api`'s ~112 call sites are deliberately NOT in this plan — they change atomically with
`writeError`'s signature and are plan 56-03's whole job. This plan exists so 56-03 has a
compiled, tested vocabulary to sweep against, and so the two out-of-`api` emitters are closed
without being trapped behind that large diff.

Purpose: freeze the vocabulary shape before any consumer (frontend, two MCP servers) is asked to
migrate onto it — PITFALLS.md Pitfall 11's explicit instruction.
Output: `internal/errcode` package, adopted by `internal/auth` and `internal/ratelimit`.
</objective>

Create `internal/errcode/errcode.go`, `package errcode`, with a package doc comment stating: this
package is the closed vocabulary of synchronous HTTP 4xx/429 `code` values; async job-failure
codes (`jobs.error_code`) are a SEPARATE already-structured vocabulary that lives beside
`EngineDescriptor` in `internal/worker` and is deliberately not re-declared here (D-04/D-06); and
that `InvalidOptions` intentionally shares its string value with the async `invalid_options`
code because the service has ONE code space (D-03).

Declare these fourteen untyped string constants with these EXACT values. The list is closed: the
granularity is one code per client-actionable failure CLASS, never one per message string (D-02).

  InvalidRequest        = "invalid_request"        // generic request/form validation: missing target, preset+target conflict, unrecognized source format, invalid callback_url, bad job id, invalid status/engine filter, invalid client_id, invalid period filter, invalid JSON body, invalid preset name
  UnsupportedConversion = "unsupported_conversion" // the (source,target) pair is not served by any engine
  InvalidOptions        = "invalid_options"        // opts present but malformed/invalid for the chosen conversion — same name as the async code (D-03)
  OptsNotApplicable     = "opts_not_applicable"    // opts are well-formed but not meaningful for this conversion
  MissingFile           = "missing_file"           // no file part in the multipart body
  UnknownPreset         = "unknown_preset"         // named preset does not exist / is not active
  PayloadTooLarge       = "payload_too_large"      // 413: body or opts field exceeds its cap
  NotFound              = "not_found"              // 404: job or preset does not exist for this client
  InvalidCursor         = "invalid_cursor"         // 400: opaque list cursor failed to decode
  AlreadyExists         = "already_exists"         // 409: preset name collision
  Unauthorized          = "unauthorized"           // 401: missing/malformed Authorization header, or invalid api key
  QuotaExceeded         = "quota_exceeded"         // 429: v1.12 quota gate — value already on the wire, must not change
  RateLimited           = "rate_limited"           // 429: internal/ratelimit — value already on the wire, must not change
  InternalError         = "internal_error"         // 5xx: anything the client cannot act on

Do not add any dependency. Do not import `internal/api`, `internal/jobs` or `internal/worker`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → API (unauthenticated) | The auth middleware's 401 body is the first bytes an unauthenticated caller sees; it must not gain any new detail |
| client → API (rate limited) | The 429 body is emitted before any handler runs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-56-04 | Information disclosure | `internal/auth` 401/500 bodies gaining a `code` field | mitigate | Codes are class-level (`unauthorized`, `internal_error`) and reveal strictly less than the already-shipping message strings; message text is byte-unchanged; the 401 does not distinguish "no such key" from "revoked key" any more than it does today |
| T-56-05 | Spoofing | A code value colliding with an async job-failure code and confusing a consumer | accept | Deliberate per D-03: the service has ONE code space, and `invalid_options` is intentionally identical across the sync and async halves |
| T-56-06 | Repudiation | Renaming `rate_limited`/`quota_exceeded` would silently break the MCP 429 handling at `internal/mcpserver/client.go:449-471` | mitigate | `TestWireValuesFrozen` and `TestRateLimitBodyCodeUnchanged` assert the literal wire strings, not the constants |
| T-56-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan; the Package Legitimacy Gate is not triggered |
</threat_model>

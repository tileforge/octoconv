The remedy is the documented fallback, at full assertion strength.

After emitting END, remove the scratch dir and exit non-zero if `emitted` differs from COUNT, so the host sees BOTH a bad exit status and a detectable count mismatch.

    Do not print progress, timing, or any request id to stdout. Do not `set -x`.

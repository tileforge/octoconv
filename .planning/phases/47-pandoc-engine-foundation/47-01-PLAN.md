<objective>
Build `PandocOpts` — the closed, strictly-parsed set of client-requested pandoc options — mirroring `OCROpts`/`AudioOpts` verbatim (PDCO-01, D-04). Fields: `standalone` bool, `toc` bool, `number_sections` bool, `wrap` enum {auto|none|preserve}, `section_divs` bool. An unknown/unlisted opt or an out-of-enum `wrap` value is rejected with an error before any work begins, and an injection test proves client bytes never reach pandoc's argv unvalidated. Add the `EnginePandoc` engine-class constant to the single source of truth.

Purpose: Establishes the client-input trust boundary for the pandoc engine BEFORE any converter core or subprocess exists — the closed allowlist + discrete-argv builder is the injection defense (T-47-03) for the new untrusted CLI surface that Plan 03 invokes. This is the classic "define the contract first" wave-0 step: Plan 03's `Convert` consumes `PandocOpts`/`pandocArgs`.
Output: `internal/convert/pandocopts.go` + `internal/convert/pandocopts_test.go` + the `EnginePandoc` constant in `convert.go`.
</objective>

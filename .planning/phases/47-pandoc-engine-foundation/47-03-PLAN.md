## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted document content -> pandoc reader | crafted TeX/HTML markup crosses into an external interpreter that can, by default, read local files (`\input`) / fetch network resources |
| converter output -> downstream consumers | a bare-fragment or corrupt output must not be accepted as a complete document |
| local pandoc binary provenance | the pandoc binary itself is a supply-chain dependency |

scripts/cad-derive-limits.py (stdlib, запускается на хосте: python3 scripts/cad-derive-limits.py EVIDENCE_DIR --pin 7.9.3.1.1 [--out FILE]; без --pin или --formula-pin скрипт отказывается работать, а --formula-pin отказывается переворачивать записанное решение пользователя)
лежит вне scripts/cad-measure/, чтобы не менять тег измерительного образа. Разбирает ROW (поле out= — остаток
строки), LADDER_STOP, DIST, CNT, PRIVATE_CORPUS, GO_WORKER, THREADS_DECISION, QUALITY и печатает каждую величину
вместе с формулой и подставленными числами:
- rss_eff строки = max(child_rss_mib, cg_peak_mib) (memory.peak включает кэш страниц; берём больший, RESEARCH).
- Пайплайн формата: STEP/IGES render = отдельные процессы mesh, затем render — пик файла равен max двух строк;
  STL render = max(stlstats, render); DXF = max(dxf, rsvg-png, rsvg-pdf). Форматы: step (вместе с stp), iges,
  stl_binary, stl_ascii, dxf.
- floor_f = максимум rss_eff пайплайна по файлам меньше 1 MiB; k_worst_f = максимум (rss_eff - floor_f) / MiB по
  файлам не меньше 1 MiB (худший файл, не средний, D-07). Если k_worst stl_binary и stl_ascii расходятся больше
  чем на 25%, у них отдельные потолки (D-08), иначе общий.
- Go = vmhwm_after_job_mib. size_max_f(L) = (0.70 * L - floor_f - Go) / k_worst_f для L = 1024, 2048, 4096 MiB.

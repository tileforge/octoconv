## Shape table (one table, two levels)

Notation: `D` = `<!doctype html>`; `B` = the UTF-8 BOM bytes EF BB BF; `T` = `<title>SAFE-<m></title>`;
`S` = `<script>document.title='BYPASS-<m>'</script>` (top-level payload: the PDF's /Title field,
the uncompressed field D-06/D-07 already judge html by); `F` = the sub-document payload
`<script>if(window!==top){var a=document.createElement('a');a.href='https://bypass.invalid/BYPASS-<m>';a.textContent='BYPASS';(document.body||document.documentElement).prepend(a)}</script>`
(acts only inside a frame; its effect is an uncompressed /URI annotation); `<m>` = a fresh
preflightMarker() per row. `at` = the byte offset where the CSP must be spliced.

| Row | Shape | Bytes | at |
|---|---|---|---|
| s1 | script before the literal html | `D S <html><head> T </head><body><p>x</p></body></html>` | len(D) |
| s2 | script between html and head | `<html> S <head> T </head><body><p>x</p></body></html>` | 0 |
| s3 | script inside head (control) | `D <html><head> S T </head><body><p>x</p></body></html>` | len(D) |
| s4 | header decoy, then script | `D <header>decoy</header> S <html><head> T ...` (rest as s1) | len(D) |
| s5 | script, then header decoy | `D S <header>decoy</header><html><head> T ...` | len(D) |
| s6 | script, then a comment containing `<head>` | `D S <!-- <head> --><html><head> T ...` | len(D) |
| s7 | comment containing `<head>`, then script | `D <!-- <head> --> S <html><head> T ...` | len(D) |
| s8 | uppercase | `<!DOCTYPE HTML><SCRIPT>document.title='BYPASS-<m>'</SCRIPT><HTML><HEAD><TITLE>SAFE-<m></TITLE></HEAD><BODY><P>x</P></BODY></HTML>` | 15 |
| s9 | BOM, then s1 | `B` + s1 | 3+len(D) |
| x1 | HTML whitespace before the doctype | `"\n\t "` + s1 | 3+len(D) |
| x2 | vertical tab before the doctype | `"\v"` + s1 | 0 |
| x3 | BOM, no doctype | `B <html> S <head> T </head><body><p>x</p></body></html>` | 3 |
| x4 | '>' inside a quoted doctype identifier | `<!DOCTYPE html SYSTEM "about:legacy-compat>">` + `S <html><head> T ...` | first '>' + 1 |
| x5 | script in body (control) | `D <html><head> T </head><body> S <p>x</p></body></html>` | len(D) |
| f1 | iframe of the raw upload | `D <html><head> T </head><body><p>b</p><iframe src="in.html" width="600" height="300"></iframe> F </body></html>` | len(D) |
| f2 | frameset of the raw upload | `D <html><head> T F </head><frameset><frame src="in.html"></frameset></html>` | len(D) |
| f3 | object of the raw upload | `D <html><head> T </head><body><p>b</p><object data="in.html" type="text/html" width="600" height="300"></object> F </body></html>` | len(D) |
| f4 | embed of the raw upload | as f3 with `<embed src="in.html" type="text/html" width="600" height="300">` | len(D) |

Unit-only edge rows (never reach Convert through LooksLikeHTML, kept for defence in depth):
e1 empty input → 0; e2 `<!doctype html` with no '>' → 0; e3 `S D <html>...` (script first) → 0;
e4 `<!-- c --> D <html>...` (comment first) → 0; e5 `B "\f\r\n" D S <html>...` → 3+3+len(D);
e6 `<html><body><script>x()</script>hi</body></html>` (the removed no-head test's input) → 0.

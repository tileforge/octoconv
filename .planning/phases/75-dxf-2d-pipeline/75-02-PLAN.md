- **texts.json contract (consumed by plans 75-04 and 75-07):** compact JSON, ascii only, `{"texts":[{"text":S,"covered":C}]}` in SVG document order; `text` equals the SVG text element content exactly; `covered` is the ordered subsequence of `text` the resolved font's cmap covers.
- **Draft contract for dxf:** the eleven keys; `format` `dxf`; `declared_unit` a vocabulary name or ``; `declared_unit_raw` the raw code as a string only when outside the table, else ``; `applied_factor` 1; `bbox` two coordinates per corner; `solids`, `closed_solids`, `volume`, `area` null; `null_reason` `not_applicable_2d`; `triangles` 0.
- `scripts/cad-dxf-probe.sh helper [--group semantics|safety|corpus|all] [--write-out]` — HELPER, FIDELITY, CORPUS rows; `--write-out` refreshes `internal/convert/testdata/cad/dxf-out/`. Row format `HELPER,group=G,case=C,input=..,sha256=..,verdict=..,reason=..,<facts>,result=ok|fail` (cases include `font_fresh_cache`, `font_warm_cache`, `text_round_trip`); each group ends with `SUMMARY,mode=helper,group=G,rows=N,fail=N`; a group re-run replaces its own lines in the evidence file.
- `internal/convert/testdata/cad/dxf-out/` — the real outputs listed in `files_modified`, with a PROVENANCE section naming the command and the image id.
- `evidence/75-02-helper.txt`.

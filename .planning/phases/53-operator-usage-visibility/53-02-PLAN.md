Add exported type `LimitWithMeta` with the seven fields listed in the `<interfaces>` block. Its doc comment must state:
- It is the operator-facing read shape (OPSV-02): one `client_limits` row joined with the owning client's identity and enforcement mode.
- `Engine` is a `*string`, nil when the client has no `client_limits` row at all — that row still carries valid `ClientID`, `ClientName` and `EnforcementMode` and MUST NOT be discarded by the caller, because "this client has no limits configured" is exactly the answer OPSV-02 asks for.
- The three limit pointers keep the same contract as `Limit`: nil is unlimited, a non-nil pointer to 0 is an explicit deny (`max_concurrent = 0` denies the engine entirely, per 0013's own comment).

Add `func (r *Repo) ListAllLimits(ctx context.Context, clientID *uuid.UUID) ([]LimitWithMeta, error)`:

- Single statement, `r.pool.Query`:
  select `c.id`, `c.name`, `c.enforcement_mode`, `l.engine`, `l.max_concurrent`, `l.max_daily_bytes`, `l.max_daily_jobs`
  from `clients c LEFT JOIN client_limits l ON l.client_id = c.id`
  where `($1::uuid IS NULL OR c.id = $1)`
  order by `c.id, l.engine`.
- Bind `clientID` directly as the `*uuid.UUID` — pgx encodes a nil pointer as SQL NULL, which is what makes `$1::uuid IS NULL` collapse the predicate to "all clients". Never interpolate the UUID into the statement text.
- Add an inline comment on the statement explaining the two deliberate choices: (a) the LEFT JOIN direction is `clients` → `client_limits`, mirroring `loadQuotaState` (admission.go:210-223), so a client with no limits row still appears; (b) the optional bind is one predicate, not two code paths (D-01).
- Copy `ListLimits`'s row-scan loop verbatim in shape: `defer rows.Close()`, `for rows.Next()` with a fresh struct per iteration, a post-loop `rows.Err()` check.
- Error wrapping per CLAUDE.md: `fmt.Errorf("list all client limits: %w", err)` for the query and the post-loop `rows.Err()`, `fmt.Errorf("scan client limit with meta: %w", err)` for the scan.
- Return a non-nil empty slice when there are no rows.
- Do not log — `internal/*` never logs.
- The `uuid` import is already present; no new imports should be needed.

Run `gofmt -w internal/clients/limits.go` before finishing.

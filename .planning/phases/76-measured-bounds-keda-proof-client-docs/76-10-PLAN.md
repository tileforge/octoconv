and receives SIGTERM, the render still finishes once, and the pod exits cleanly within the production grace period (D-08).
Then return the shared k8s cluster to the state it was in before phase 76.

Purpose: SC2 "downscale-survival". 76-04 derived the grace chain from the measured engine timeout. This is the live proof
that asynq's ShutdownTimeout and the pod's terminationGracePeriodSeconds protect a job.

Output: the overlay key, `scripts/keda-cad-downscale-survival.sh`, the calibration and survival evidence.
</objective>

Шаг 1 — создать `internal/convert/exportedapi_test.go` (package convert).
Хелпер `engineExecLeaks(pkg *types.Package) (leaks []string, examined int)`.
Он обходит `pkg.Scope().Names()`, берёт экспортированные (`token.IsExported`)
и для каждого считает examined++. Правила по виду объекта:
- `*types.Func`, `*types.Var`, `*types.Const` — проверить `o.Type()`, в отчёт
  имя объекта.
- `*types.TypeName`, alias (`o.IsAlias()`) — проверить `o.Type()`.
- `*types.TypeName`, named — по underlying. Struct — только экспортированные
  поля, в отчёт `Type.Field`. Interface — только экспортированные методы, в
  отчёт `Type.Method`. Иначе — сам underlying (func-типы), в отчёт имя. Плюс
  pointer method set `types.NewMethodSet(types.NewPointer(named))`: только
  экспортированные методы, в отчёт `Type.Method`.

Рекурсивная проверка «упоминает» с seen-множеством (от циклов):
- Alias → `types.Unalias`.
- Named → true, если это `engineExec` ЭТОГО пакета (`obj.Pkg() == pkg && obj.Name() == "engineExec"`,
  по идентичности объекта, не по тексту). Иначе проверить `TypeArgs()`. Если
  это unexported named-тип этого пакета — рекурсия в `Underlying()`:
  экспортированная функция, принимающая unexported обёртку вокруг
  `engineExec`, — тот же дефект. Прочие named → false: экспортированные типы
  проверяются по их собственной поверхности.
- Pointer / Slice / Array / Chan → elem.
- Map → key и elem.
- Signature → все params и results.
- Struct → все поля. Interface → все методы.

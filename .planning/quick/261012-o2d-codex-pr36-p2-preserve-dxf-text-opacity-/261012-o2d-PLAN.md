# Quick 261012-o2d: carry DXF text opacity into the SVG (codex PR #36 P2)

## Objective

Codex P2 on PR #36: `cad-dxf` writes text colour as `t["color"][:7]`, dropping the alpha that ezdxf
resolves into `properties.color` (entity, ByLayer and ByBlock transparency), so transparent TEXT/MTEXT
becomes opaque in the client SVG and in the PDF/PNG made from the render-only SVG. Fix the class: every
site where `cad-dxf` writes a colour into SVG must carry alpha the way `resolve_color` does, and the Go
side (allowlist, cross-check, PDF judge, preflight, pixel judge) must stay correct for faint and
invisible text.

## Rules fixed before any code

- **Opacity:** a text's opacity is ezdxf's `alpha_to_opacity(color[7:9])`, the function behind
  `SVGRenderBackend.resolve_color`; it is written as `fill-opacity="%.3f"` only when below 1, the same
  format the stroke and fill paths use. Opaque text stays byte-identical to today's output.
- **Invisible:** a text is invisible when its alpha is `00` (written `fill-opacity="0.000"`). texts.json
  carries `"invisible": true` for it and omits the key otherwise. The Go validator computes each text's
  effective fill opacity (own or inherited from `g`, `fill="none"` counts as 0, a `tspan` can only raise
  it); the cross-check requires the flag to equal "effective opacity is 0" and the client and
  render-only SVG to agree text by text.
- **PDF judge:** an invisible text is excluded from the in-order text expectation and counted as
  `InvisibleText`/`InvisibleRunes` (beside `BelowRenderFloor`); a flag that disagrees with the SVG is a
  rejection. Partially transparent text stays required.
- **Bbox and frame:** geometry, not paint. Every drawn primitive counts whatever its opacity, text and
  shapes alike; this is what ezdxf's recorder bbox (and so `drawn_box`) already does for fully
  transparent shapes. Consequence, documented: a drawing whose only content is fully transparent has a
  frame but no ink, so PDF and PNG are rejected as showing nothing.
- **Pixel judge:** faint ink is ink (opaque mask is any channel below 250, transparent mask is alpha
  above 0); proven by a unit test and by real helper frames of a drawing whose only ink is 50% text.

If the ignore line were removed, it would still commit nothing, because the parent's `git add` silently skips paths inside the embedded repo (`nothing_to_commit`). Only `commit-to-subrepo` commits into the planning repo, and only when the operator sets `planning.sub_repos: [".planning"]` in .planning/config.json explicitly, since auto-detection skips dot-directories. - list both the code root and `.planning` as sub-repos (not tested here);
- change gsd-tools.

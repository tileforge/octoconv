<objective>
`LooksLikeHTML` (internal/convert/htmlsniff.go:43) opens with a hand-rolled copy
of what `readSniffPrefix` (internal/convert/markupsniff.go:45) already does:
`size <= 0` guard, clamp to `htmlSniffCap`, bounded `ReadAt`, empty check, NUL
check, `utf8.Valid`. Because it is a *copy*, it never received the PR#2
finding-2 fix delivered in quick task 260802-9de: when a file exceeds the 1 MiB
cap and the cut lands inside a multi-byte rune, the dangling lead byte makes
`utf8.Valid` fail and a perfectly valid HTML document is rejected as
unrecognized content.

`readSniffPrefix(r, size, htmlSniffCap)` returns exactly the `(buf, ok)` pair
this function needs, with identical check ordering (NUL and UTF-8 validated on
the raw prefix; BOM/whitespace trimmed afterwards by the caller). So this is a
substitution, not a rewrite: delete the duplicated prologue, call the shared
helper, leave the marker scan below byte-for-byte untouched.

Purpose: close the last surviving instance of the mid-rune truncation defect,
and remove the duplication that let it survive the first fix in the first place.
Output: `LooksLikeHTML` reduced to BOM/whitespace trim + marker scan, three new
regression tests, and one stale doc comment in `markupsniff.go` corrected.

Blast radius is real — two production callers depend on this verdict:
- `internal/api/handlers.go:240` — the upload content gate for declared-html sources.
- `internal/convert/pandoc.go:253` — output validation for every `-> html` pandoc conversion.
</objective>

From internal/convert/markupsniff.go:
  func readSniffPrefix(r io.ReaderAt, size int64, cap int64) ([]byte, bool)
  func trimPartialTrailingRune(buf []byte) []byte
  func leadByteRuneLen(b byte) int

readSniffPrefix's exact contract (matches LooksLikeHTML's current prologue
step-for-step, plus the truncation trim LooksLikeHTML is missing):
  1. size <= 0                       -> (nil, false)
  2. n = min(size, cap); ReadAt(buf, 0); non-EOF error -> (nil, false)
  3. buf = buf[:read]; len == 0      -> (nil, false)
  4. if size > cap && read >= cap    -> buf = trimPartialTrailingRune(buf)
                                        (emptied by the trim -> (nil, false))
  5. bytes.IndexByte(buf, 0) != -1   -> (nil, false)
  6. !utf8.Valid(buf)                -> (nil, false)
  7. otherwise                       -> (buf, true)

Step 4 is the ONLY behavioural difference from what LooksLikeHTML does today,
and it fires only when the cap genuinely severed the prefix.

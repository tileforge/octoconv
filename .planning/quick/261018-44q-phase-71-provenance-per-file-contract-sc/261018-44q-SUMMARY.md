## Deviations from Plan

**1. [Rule 2] A refusal needs the content-check message.** The plan defines a refusal as exit 1 with an ok=0 GOJUDGE
line, with rule `unknown` when no known token follows. But the Go judge also exits 1 with ok=0 when it rejects its
arguments (`judge size 7 is outside ...`) or cannot read the file. Those are judges that did not judge. `go_verdict`
reports them as `ok=error`. Content-check refusals without a known token would still get `rule=unknown`. Evidence:
the `--size 7` control in `judge-png.txt`.

**2. [Rule 1] The judge-mode `evid_put` pattern still lists PIX and DIVERGENCE.** It is the pattern of lines removed
from an existing evidence file. If the two prefixes were dropped from it, a re-run would leave the retired lines next
to the new GOJUDGE verdicts. I read "drops PIX and DIVERGENCE" as "removes them".

**3. [Rule 2] Selection failures stop the run.** The `< <(list_cad_files ...)` loops in rss-time and the prune input
loops in image-trace discarded the selection's exit status. A corpus root without `public/` would have become an
empty success. Each selection is now captured first:
- rss-time: exit 64 for an argument directory, 1 for the private corpus.
- image-trace: `set -e` stops the run.

**4. Shellcheck clean-up went further than the named line.** Renaming the unused loop variable at image-trace :246 to
`_` made shellcheck flag the next unused `i` in the same `ops_fixture`. All four loops there now use `_`. The
render-probe baseline is info 6 plus style 1, not info 7 and style 0 as the plan said. The plan's gate counts gcc
notes (7), which covers both, so the gate's meaning is unchanged.

**5. Formatting only.** The identity `IDENTITY_DIFF` printf and its `docker run ... pixelcheck.py same` argument are
joined into one line, so the plan's `awk '/pixelcheck/ && !/ same /'` gate holds. Behaviour is unchanged.

**6. Extra evidence beyond the plan:** `inventory-stub.txt` (a stub-docker run of the inventory),
`judge-pair-harness.txt` (judge mode's `judge_pair`, `go_verdict` and `blank_png` extracted and run on render-bg), the
decode, J0 and argument-error controls, and the pixel-table negative check (two mutated expectations both gave
`PIXEL-TABLE-DIFFERS`).

**7. The 27 scripts of the syntax check** are the 27 `scripts/` entries of the covered list, which already include
`cad-render-probe.sh`.

  test re-hashes on every run. M1-M4 fail both the test and the gates.

- **T-44q-03 (Tampering, go_verdict): mitigated.** Only exit 0 with ok=1, or exit 1 with ok=0 and a content-check

  becomes a bad row), tracer (the stage needs ok=1) and judge-png (exit 1). Proven by the missing-path and
  argument-error controls.
- **T-44q-04 (DoS, live stack): mitigated.** No docker, kubectl or helm ran. judge-png is proven docker-free with a
  logging stub.
- **T-44q-SC (package installs): accepted.** No package was installed.

## What changed

- `cmd/cad-worker/helper/cad-mesh`:
  - Module-level `VERTEX_RE` and `VERTEX_KEY_RE` are compiled with `re.IGNORECASE`.
  - `last_keyword()` scans backwards in 1 MiB windows with a 5-byte overlap. It does not copy or lowercase the block.
  - `stats_write()` writes the header `octoconv normalized binary stl`, the count, and records in 65,536-triangle chunks. The float32 cast runs under `errstate(over="ignore")`, and a non-finite value refuses the file. The writer requires the size to equal 84 + 50n.
  - On failure, `stats_discard()` removes the partial file.
  - The stats argv is now `stats --measure M src out`.
  - The shebang is still the only `#` line.
- `internal/convert/cad.go`: `statsStage(ctx, jobDir, inPath, outPath, measure)`.
- `internal/convert/cadrender.go`:
  - `renderInput` is `jobDir/mesh.stl` for every format.
  - An input whose cleaned path equals that file is refused before any stage runs.
  - After either branch, every format runs the same checks: `judgeBinarySTL`, then `requireSTLMatchesVerdict`, then the new check that draft triangles equal n (`ErrCADMeasurementsInvalid`). The STL special case that took its triangle count from the draft is gone.
- `internal/convert/cadrender_test.go`:
  - The STL argv test now checks exact argv for stats and render.
  - New refusal table: missing mesh, verdict mismatch, client ASCII bytes as mesh, draft mismatch.
  - New tests: STEP draft-mismatch, and an input at the mesh path (clean and `./`).
  - The cap boundary test now uses a sparse, symlinked STL of exactly the cap.

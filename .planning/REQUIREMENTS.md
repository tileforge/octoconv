# Requirements: OctoConv v1.14 — Typesetting & Debt

**Defined:** 2026-09-02
**Core Value:** Внутренние сервисы компании могут безопасно и надёжно поставить задачу обработки файла и получить результат — без риска для стабильности или безопасности продакшена.

## v1 Requirements

### Typesetting (tectonic, ninth engine class)

- [ ] **TEX-01**: Клиент может отправить `.tex` с `target=pdf` и получить свёрстанный PDF — реальная типографика с формулами, ссылками и библиографией, а не HTML-рендер
- [ ] **TEX-02**: Сборка идёт **без сетевого доступа**: в образ вшит offline-бандл TeX-пакетов, запиненный по версии и содержимому, и воркер не имеет egress — документ клиента не может решать, что будет скачано
- [ ] **TEX-03**: Набор поддерживаемых LaTeX-пакетов **закрыт и объявлен**: документ, использующий пакет вне набора, получает внятный отказ с указанием пакета, а не молчаливо иную вёрстку
- [ ] **TEX-04**: Shell escape (`\write18`, `\input{|cmd}`) невозможен из содержимого документа, и это доказано прогоном на враждебном документе плюс инверсией, а не ссылкой на документацию
- [ ] **TEX-05**: `tex` — полноценный девятый engine-класс по отлаженному шаблону: своя очередь, `cmd/tectonic-worker`, свой контейнер, transient/terminal классификация, **ИЗМЕРЕННЫЙ** на корпусе с многопроходными документами таймаут, девятый ScaledObject, оставляющий существующие восемь байт-неизменными

### Sanitize hardening

- [ ] **SANI-07**: ICC-профиль, разбитый на несколько APP2-сегментов, сохраняется целиком: проверка размера применяется к собранному профилю и полям sequence/count, а не к каждому чанку по отдельности
- [ ] **SANI-08**: Границы потоков PDF определяются по `/Length` из словаря потока, а не по первому вхождению подстроки `endstream` — так что бинарный поток, содержащий эти байты, не обрезает защищённый диапазон ни для редакции, ни для подсчёта ревизий
- [ ] **SANI-09**: Санированный OOXML-пакет, у которого relationship нацелен на его собственную главную часть, отвергается, а не отдаётся пустым: верификатор требует наличия ожидаемой главной части и её объявления типа

### Probe input bounds

- [ ] **PROBE-01**: Документ, число страниц которого превышает `PROBE_MAX_PAGES`, отвергается **при приёме** с машиночитаемым `too_many_pages`, а не падает по таймауту после десяти минут работы воркера
- [ ] **PROBE-02**: Отказ по числу страниц классифицирован **терминально** и не тратит бюджет ретраев — в отличие от таймаута, который остаётся транзиентным, потому что зависит от нагрузки, а не от файла

### Operational debt

- [ ] **DEBT-12**: Свежая установка чарта не даёт api-поду крашлупить: контейнер ждёт готовности Postgres вместо `exit(1)` на каждой попытке, и `restartCount` при чистом старте равен нулю
- [ ] **DEBT-13**: Полный прогон `go test ./...` на живой базе детерминирован: soak-тест реконсилятора больше не может быть сломан in-flight джобой параллельного пакета
- [ ] **DEBT-14**: Отчёт `POST /v1/inspect` не может одновременно утверждать `coverage.complete: true` и `unknown/read_failed` во всех своих проверках — «я прочитал файл полностью» и «я не смог его прочитать» перестают уживаться в одном теле ответа

## v2 Requirements

Отложено, отслеживается, не в этом роадмапе.

### Pipelines

- **PIPE-01**: `md → pdf` одной джобой через цепочку pandoc → tectonic — первая джоба, пересекающая границу движка; своя история про квоты, ретраи и частичный отказ (SEED-018)

### Typesetting extensions

- **TEX-06**: Расширение закрытого набора пакетов по запросу потребителя, с документированной процедурой пересборки бандла
- **TEX-07**: `latex → pdf` с пользовательскими шрифтами

## Out of Scope

| Feature | Reason |
|---------|--------|
| Полный бандл TeXLive в образе | ~2.69 GiB на слой — на порядок больше любого воркера во флоте; закрытый набор пакетов и дешевле, и честнее (см. `.planning/research/TECTONIC.md`) |
| Сетевой доступ у tectonic-воркера | Документ клиента решал бы, что скачивается — ровно тот вектор, который `sanitize` вычищает из чужих файлов |
| `md → pdf` в этом милстоуне | Пересекает границу движка; принадлежит SEED-018, а не сюда |
| Архивация 26 quick-каталогов как «работа» | Это завершённая работа с незаархивированными каталогами, а не открытые баги — чистка, не требование |

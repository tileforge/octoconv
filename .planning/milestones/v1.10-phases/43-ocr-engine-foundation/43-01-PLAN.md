<objective>
Build `OCROpts` — the closed, strictly-parsed set of client-requested OCR options — with `Language` validated against a closed allowlist (`eng`, `rus`, combinable as `eng+rus`), mirroring `AudioOpts` verbatim (OCRO-01). An unlisted code is rejected before any work begins, and an injection test proves client bytes never reach Tesseract's `-l` argv unvalidated.

Purpose: Establishes the client-input trust boundary for the OCR engine before any converter core or subprocess exists — the language allowlist is the injection defense for the two new untrusted CLI processes (tesseract/poppler) that later plans invoke.
Output: `internal/convert/ocropts.go` + `internal/convert/ocropts_test.go`.

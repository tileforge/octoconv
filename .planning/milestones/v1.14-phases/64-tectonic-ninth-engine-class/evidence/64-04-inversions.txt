----------------------------------------------------
Both verdicts are pinned in ONE test through NewRunner(h,
TectonicDescriptor).Handle, and both were made to fail on purpose.

(a) Removed "unrecoverable error" from isTectonicTerminal's signature list:

    --- FAIL: .../compilation_error_is_terminal

        an unrecoverable error | caused by: halted on potentially-recoverable
        error as specified, want errors.Is(err, asynq.SkipRetry)

    through to isTerminal:

T4. Inversion on the bundle-path plumbing
------------------------------------------
buildTectonicConverter changed to return convert.TectonicConverter{} --
the exact "configured but not plumbed" defect this fleet has shipped once:

    --- FAIL: TestBuildTectonicConverter
        main_test.go:27: buildTectonicConverter("/opt/tectonic/some-other-bundle.ttb")
        .BundlePath = "", want "/opt/tectonic/some-other-bundle.ttb"

Note what the startup path would have done with that build: main() stats the
resolved path, finds it readable, logs it, and starts consuming the queue --
then every job refuses, because the converter it registered has no bundle.
The failure would look like nine hundred bad documents.

64-03 T3. Inversion on the worker's unsupported-package branch
---------------------------------------------------------------
Removed the errors.Is(ErrTeXUnsupportedPackage) branch from isTectonicTerminal
AND the naming branch from tectonicFailureCode:

    --- FAIL: .../unsupported_package_is_terminal_and_names_the_package
        pinning_test.go:1174: MarkFailed code = "engine_error", want
        "unsupported_package" -- the SAME string cmd/api returns when its
        bounded scan catches this first (one code space, D-03)

Note WHICH half failed. The verdict stayed TERMINAL even with its branch
removed, because the engine's output contains "LaTeX Error" and the signature
list catches it -- so the terminal classification is covered twice over. What
the branch actually buys is the CODE and the MESSAGE: without it the client is
told "the document could not be typeset" and has to find the package
themselves. An inversion that only asserted the verdict would have reported
success here and proved nothing.

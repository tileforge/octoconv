## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM-агент → MCP-сервер (`convert_file`) | Значение `operation` приходит из генерации модели — полностью недоверенный ввод |
| MCP-сервер → `POST /v1/jobs` | MCP выступает прокси; он не должен становиться вторым источником истины о возможностях |
| Браузер → `POST /v1/jobs` | Референсный SPA; значение `operation` контролируется пользователем |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-57-30 | Elevation of Privilege | Локальный allowlist операций в MCP или во фронтенде | mitigate | Ни один вход не валидирует `operation` локально — значение прокидывается как есть, решение принимает fail-closed гейт `IsKnownOperation` в `handleCreateJob` (план 57-04). Второй источник истины разошёлся бы с реестром и открыл бы окно между «клиент считает операцию доступной» и «API её отвергает» |
| T-57-31 | Tampering | Multipart-тело запроса без операции | mitigate | Пустое значение не пишется в тело вообще (guarded-append) — форма запроса существующего клиента байтово не изменилась; запинено тестами и в Go, и в TS |
| T-57-32 | Information Disclosure | Сообщение об ошибке во фронтенде | mitigate | Ветка `unsupported_operation` отдаёт серверный `message`, а при его отсутствии — собственный нейтральный текст; перечень доступных операций в сообщение не встраивается, его отдаёт аутентифицированный `GET /v1/formats` |
| T-57-33 | Integrity | Потребление `outputs[]` фронтендом | accept | Тип объявлен необязательным, UI сегодня его не рендерит: у convert-джобы один выход и ключа нет. Основным результатом остаётся `download_url`, что зафиксировано комментарием в типе |
| T-57-34 | Denial of Service | Расхождение версий фронтенда и API | mitigate | `FormatsResponse.operations` и `JobStatusResponse.outputs` объявлены необязательными — SPA переживает ответ API без этих ключей; проверено тестом разбора ответа без `operations` |
| T-57-SC | Tampering | npm/pip/cargo installs | accept | План не добавляет ни одной новой npm- или Go-зависимости: изменения — только в существующих исходниках, `package.json` не трогается. Проверка: `git diff --name-only frontend/package.json frontend/package-lock.json go.mod go.sum` печатает пустой вывод. Package Legitimacy Gate неприменим |

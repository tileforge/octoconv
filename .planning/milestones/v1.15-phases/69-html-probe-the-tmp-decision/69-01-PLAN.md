Planner findings that correct the research and are built into this plan (read before executing):
- `forJob` has no slot for writable paths beyond the job directory; html needs `/tmp` and
  `/dev/null`, so this plan adds `forJobRW` (forJob becomes forJobRW with no extras).
- `ChromiumConverter.Convert` copies the input into the job directory (`rendered.html`) before
  the engine runs, so `Convert(outsideFile)` would render the marker and prove nothing. The
  negative run has to point the ENGINE at a file outside every grant, with the same argv
  builder and ruleset. Chromium exits 0 with a blank 652-byte PDF when denied, so
  `requireDenied`'s "a nil conversion error is a failure" rule cannot judge it; this plan adds
  `requireAbsent` (the marker judgment on its own), which `requireDenied` then reuses.
- The preflight workspace lives under `os.TempDir()` (`/tmp`), which html grants read-write.
  An outside directory there would be readable, and the preflight would refuse every start.
  The html preflight places its outside directory under `/var/tmp`, and `requireOutsideGrants`
  proves the location is outside every grant.
- The worker creates every job directory with `os.MkdirTemp("", ...)`
  (internal/worker/worker.go:1369), i.e. under `/tmp`. The sweep must keep the current job's
  directory, and a process-wide `os.Setenv("TMPDIR", ...)` (research's probe sketch) would
  break every later job's directory creation. The decision section records this; probe's
  per-exec `TMPDIR` lands in plan 02.
- html grants `/proc` wholesale, so the engine can read `/proc/self/environ`, which carries
  DATABASE_URL and the S3 keys. tectonic hit the same leak and answered it with an allowlisted
  environment (`tectonicEnv`, tectonic.go:1103-1148). This plan applies that answer to
  chromium through the same `engineExec`.
- `HTML_WORKER_CONCURRENCY` appears once in docker-compose.yml (not five times as the research
  said); `queue.TestComposeReplicatesEveryEngineVarToEveryQueueClientService` checks only
  `*_ENGINE_TIMEOUT`/`*_MAX_RETRY`. The four places to change are main.go, compose, `.env.example`
  and the chart ConfigMap.
- The wrapper's real bytes are `#!/bin/sh -e`, a blank line, then
  `/usr/lib/chromium/chromium-headless-shell "$@"` (61 bytes, no `exec` keyword; research
  correction to CONTEXT D-08's paraphrase).

Output: html confined and live-gated; shared `forJobRW`/`withEnv`/`engineEnv`/`sharedTmpGuard`/
`requireAbsent`/outside-workspace pieces that plan 02 reuses; the CONF-06 record.

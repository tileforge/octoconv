<objective>
Confine the probe class: every external engine the sanitize path execs — `pdfinfo`, `gs` ×2,
`unzip` ×2, `file` ×2 (six call sites, four binaries, re-measured from the code per D-10) —
runs under one Landlock ruleset per job with no `/tmp` (D-05), proven at startup by a
content-judged preflight over all four engines, with the worker refusing to start without
Landlock. Per D-09 only the external engine execs are confined; pdfcpu and the Go-side
OOXML/zip/image handling stay in-process and unconfined (recorded as deferred).

Planner findings built into this plan (they change the research's recommendations):
- Research sketched `os.Setenv("TMPDIR", ...)` in the worker process. Rejected: the worker
  creates every job directory with `os.MkdirTemp("", ...)` (internal/worker/worker.go:1369), so a
  process-wide TMPDIR pointing into one job's directory makes the next job's directory creation
  fail once that directory is removed; it also races at concurrency above 1. TMPDIR is set in
  each engine's OWN environment through plan 01's `engineExec.withEnv(engineEnv(jobDir))`. This
  answers RESEARCH Open Question 2: with per-exec TMPDIR and no shared writable path, concurrent
  probe tasks share nothing, so no probe-specific guard is needed; `ProbeConcurrencyGuard` is
  still called, keyed on the grant set, so re-adding `/tmp` to probe would trip it.
- The probe dispatch maps have fixed function-value types, so threading `x engineExec` changes
  `sanitizeFormats`, `verifiers`, `sanitizePageCeilings`, `SanitizeFile`, `VerifySanitized`,
  `probePDFPageCount`, `enforcePDFPageCeiling` and all six format functions, and ~60 test call
  sites in 14 files. No unconfined convenience wrapper is kept: a caller must decide, and tests
  pass `engineExec{}` explicitly.
- `unzip` and `file` only ever read the job-directory OUTPUT, and `pdfinfo`/`gs` read the input —
  so `Convert(outsideFile)` is a meaningful negative only for the PDF route. The preflight
  therefore runs each engine directly, through the job's engineExec, on an outside copy, and
  judges by content (`file` prints "no read permission" and exits 0 when denied).
- `classifyEngineFailure` and the four verifier wraps flatten the sandbox sentinel with `%v`
  (research Pattern 3); fixed at every wrap point, then in `isProbeTerminal`.
- TestVerifierRejectsTheUnsanitizedInput verifies files under testdata/ directly; with the
  verifier's scratch directory beside its input, it would write into the source tree. It copies
  the fixtures into t.TempDir() first.

Output: probe confined and live-gated; the probe section of SANDBOX-PATHS.md corrected.
</objective>

- `scripts/sandbox-liveproof.sh`: the per-class live gate, calibrated on phase 67's image.

Purpose: prove the architecture on the simplest class (one static binary, one call site)
before three more classes are built on it.

Same process handling as runCommand (Setpgid, SIGKILL of the process group on ctx.Done, unbounded tail buffers, stdout returned even on non-zero exit), but every error shape names label instead of name: "start <label>: …", "<label> killed: %w", "<label> failed: %w: <stderr>".

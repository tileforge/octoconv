<objective>
Wave-0 measurement for phase 68 (discovery, kept apart from implementation): re-measure
what each of the four classes actually execs and reads ON A JOB'S PATH, using the
existing tool `scripts/sandbox-paths-measure.sh` against freshly built images, judge
every result by CONTENT, and record the proven sets in SANDBOX-PATHS.md in a form the
Go pinned-set tests can be diffed against mechanically.

Why this is not a formality (per the orchestrator's decision 2 and 68-RESEARCH.md Pitfall 1):
- the documented OCR set grants only tesseract and pdftoppm, but every PDF job runs
  `pdfinfo` first and `txt` targets run `pdftotext` — neither was ever measured;
- the OCR image has /etc/fonts and /usr/share/fonts/truetype/dejavu, and born-digital
  PDFs with non-embedded fonts need them to render: without them pdftoppm can exit 0
  with glyphs missing and tesseract then returns empty text, which the converter accepts
  as a valid result — the ghostscript trap (SANDBOX-PATHS.md pitfall 8) in a new place;
- the audio set lacks `/usr/bin/ffprobe`, which the duration guard runs on every job;
- the av set was measured without the ffprobe audio-codec probe, the progress output,
  the hevc/webm/extract/thumbnail argv, or the source generation the AV preflight will use;
- the audio model is configurable (AUDIO_MODEL_PATH), so the set should grant the model
  FILE at run time rather than a /models directory.

Output: SANDBOX-PATHS.md sections with the proven sets and conf05 blocks;
`scripts/conf05-crosscheck.sh` used by plans 03–06.
</objective>

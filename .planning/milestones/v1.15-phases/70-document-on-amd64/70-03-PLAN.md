<objective>
Confine the document class in code, on the sets 70-02 measured: soffice and veraPDF each under its
own ruleset built once per task, an allowlisted engine environment, a content-judged preflight over
both engines, a worker that refuses to start without Landlock, and the class's generic live gate
on a freshly built image. The deployment configuration (compose, .env.example, chart) and the
document-only live checks -- the emulated amd64 image's refusal (D-08) and the /tmp route checks --
are 70-04's, split out so this plan keeps room to fix what its own gates find.

Reads first: 70-01-SUMMARY.md "## Route decision" (the socket right), 70-02-SUMMARY.md (`/tmp
route:`, `pipe residue:`, `SOFFICE-DENIAL:`, the preflight fixture part list, the preflight-shaped
seconds) and SANDBOX-PATHS.md's document section and conf05 blocks. Steps below say which route
they depend on; everything else is route-independent.

Planner findings built into this plan:
- Unlike chromium, LibreOfficeConverter.Convert passes inPath to soffice directly and never copies
  it into the job directory, so Convert on an outside file IS a meaningful negative through the
  production path. The negative output is judged by content (content.xml), because whether soffice
  fails loudly or silently was only just measured (70-02).
- ValidatePDFA is a package-level function called from validateDocumentOutput. It gets the job's
  veraPDF engineExec threaded in explicitly (the probe precedent), not a package-level sandbox
  setter: tests pass engineExec{} and run veraPDF directly.
- The current classifier would read a veraPDF sandbox fault as terminal: ValidatePDFA wraps a
  run error with no stdout as "pdf/a validation error", a terminalVeraPDFSignatures entry. The
  sentinel check first in isDocumentTerminal is what keeps that a node fault.
- cmd/document-worker connects to Postgres as its first act today; the refusal and preflight move
  in front of it (probe-worker's order). SetVeraPDFTimeout moves up too: the preflight runs
  ValidatePDFA.
- The preflight's outside directory goes under /var/tmp, like html's: a socket grant (or a
  read-write grant) on /tmp would otherwise put an outside file beneath a granted path.

Output: document confined and passing the generic live gate; 70-04 wires the configuration and the document-only checks.
</objective>
